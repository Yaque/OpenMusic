# OpenMusic 音准练习 App — 需求分析与设计

> 基准项目：https://github.com/yaque/openmusic （AGP 9.3.3 + Kotlin 单模块模板）
> 目标用户：音乐初学者（零基础识谱 / 音准训练）

---

## 一、原始需求（用户表述）

1. 配置 Android 开发编译环境；
2. 设计一个 Android app，供音乐初学者**弹钢琴练习自己的音准**；
3. 功能：
   - **钢琴界面**：用户弹一个键，出一个声；
   - **同时录音**监听用户唱的音是否准确，并给出用户唱的是什么音；
   - **7 个音的随机出现**，让用户选择是哪个音，或唱出是哪个音。

---

## 需求补全（2026-10-16 用户反馈更新）

- **听音音域**：播放音覆盖 **C 大调全部自然音 C3–C6**（29 个音，可切回中音区 C4–B5）；作答仍是 7 个唱名（音名相同、八度不同算同一音级）
- **八度宽容判定**：演唱/模唱时，**同音名跨八度算唱对**（男声低八度唱 C4 → C3 判「音名正确（低八度）」），评分基于到最近八度的音分偏差；音名不对才判「音没对上」

## 二、需求补全（表述不清晰处的分析与决策）

| # | 待澄清点 | 分析 | 决策 |
|---|---|---|---|
| 1 | “7 个音”指什么 | 初学者语境 = 自然大调 7 个音级 do re mi fa sol la si（对应 C D E F G A B） | 以 C 大调 7 个音级为核心对象，同时展示**音名（C4）/ 唱名（do）/ 简谱（1）** 三种标记，降低识谱门槛 |
| 2 | “弹一个出一个声”音源从哪来 | 无采样文件也需发声；真钢琴采样体积大、授权杂 | **运行时加法合成**钢琴音色（谐波叠加 + 指数衰减包络），零网络依赖、即时响应；App 依赖（AndroidX/Material）由 Gradle 从网络获取 |
| 3 | “录制声音监听”实时性 | 需要麦克风权限 + 实时音高检测 | `AudioRecord` 44.1kHz 采集 → **YIN 基频检测算法**（自研，纯 Kotlin，可单测）→ 音名 + 音分级偏差；需 `RECORD_AUDIO` 运行时授权 |
| 4 | “唱的是否准确”怎么算准 | 音准 = 音高偏差 | 用**音分（cents）**度量：`cents = 1200·log2(f_唱 / f_目标)`；\|cents\|≤25 很准、≤50 基本准、>50 偏高/偏低；连续稳定帧求均值打分（0–100） |
| 5 | “随机出现…选择”还是“唱出”，是两种还是一种 | 语法上是并列的两种作答方式 | 测验模式提供两种作答方式切换：**① 听音选择**（听声 → 点 7 个唱名按钮）；**② 模唱**（听声 → 唱出 → 麦克风判定） |
| 6 | 弹琴发声会不会干扰唱歌识别 | 扬声器外放钢琴声会被麦克风拾取，是音准类 App 的共性问题 | 三条缓解：① 识别起始延迟 300ms（躲开琴键起音）；② 置信度/能量门限 + 中值平滑，只在“检测到人声持续音”时出结果；③ 界面提示**戴耳机**练习；模唱模式采用“先放标准音→静音→再唱”的先后时序，彻底避免串音 |
| 7 | 音域范围 | 人声一般 80Hz–1.1kHz；初学者音域更窄 | 识别范围 70–1000Hz；练习音选 C4–B5 两个八度（钢琴界面 C4–C6 全键位） |
| 8 | 界面形态 | 功能分三块 | 单 Activity + 底部导航三页：**钢琴实验室 / 听音选择 / 模唱练习**，另含结果统计卡片 |

## 三、功能规格

### 1. 钢琴实验室（Piano Lab）
- 88 键中截取 **C4–C6 共 17 个白键 + 12 个黑键**，支持多点触控，按下高亮、发声（加法合成，1.2s 自然衰减 + 释放）。
- 每按一键：显示目标音（音名/唱名/简谱），同时启动麦克风监听：
  - 实时显示**唱出来的音**（如 `A4 · la · 6`）；
  - 音分偏差条（-100 ~ +100 cents），指针居中为准；
  - 判定文案：`很准 ✓` / `基本准` / `偏高 ↑` / `偏低 ↓`，配色反馈（绿/黄/红）。
- 一次练习记录得分（稳定帧平均 |cents| → 0–100 分），累计统计。

### 2. 听音选择（Ear Training）
- 随机播放 7 个音级之一（C4–B4，可开扩展音域 C4–B5）。
- 7 个唱名按钮（do re mi fa sol la si，附音名/简谱），点选判定对错；
- 反馈：答对 ✅ +1 分、连击 streak；答错 ❌ 显示正确答案；
- 统计：正确率、连击数、答题数。

### 3. 模唱练习（Sing Test）
- 时序：播放标准音（1.5s，钢琴音色）→ 提示“请唱出这个音” → 录音识别 5s → 判定。
- 显示：目标音 vs 识别音、音分偏差、评分（0–100）、评语（很准/偏高/偏低）。
- 可选择“显示音名”或“隐藏音名（盲唱）”增加难度。

## 四、技术架构

```
com.aiocw.openmusic
├── MainActivity.kt            # 底部导航宿主 + 麦克风权限调度
├── audio/
│   ├── PianoSynth.kt          # AudioTrack 多声部加法合成钢琴音（纯 PCM 生成器可单测）
│   ├── MicPitchMonitor.kt     # AudioRecord 采集线程 + 回调
│   └── PitchEngine.kt         # ★ YIN 基频检测（纯 Kotlin，JVM 单测）
├── music/
│   ├── Note.kt                # ★ 音名/唱名/简谱/MIDI/频率换算（JVM 单测）
│   └── NoteUtils.kt
├── ui/
│   ├── PianoView.kt           # 自定义钢琴键盘 View（多点触控）
│   ├── PianoLabFragment.kt
│   ├── EarQuizFragment.kt     # 听音选择
│   ├── SingTestFragment.kt    # 模唱
│   └── ScoreBoard.kt
```

- **音高检测**：YIN（de Cheveigné & Kawahara 2002），差分函数 + 累积均值归一化 + 阈值 0.12 + 抛物线插值；窗口 4096 样本、hop 1024（44.1kHz）；输出 f0 + 置信度。
- **合成钢琴**：8 次谐波幅度包络 `[1, .55, .30, .18, .12, .08, .05, .03]`，基频按十二平均律；ADSR：快起音 8ms、指数衰减（高频衰减更快）、120ms 释放；音量随音高轻微补偿。
- **权限**：`RECORD_AUDIO` 运行时申请；拒绝后隐藏监听功能并引导去设置。
- **兼容**：minSdk 30 / targetSdk 37（沿用基准），Kotlin + Material3 深色主题。

## 五、资源获取说明

- 构建依赖（AGP 9.3.3、AndroidX、Material 1.14）通过 Gradle 从 google()/mavenCentral() 获取；
- 钢琴音色为**运行时合成**，不依赖网络采样资源，离线可用；
- 音高识别算法自研实现，不引入第三方 DSP 库（避免体积/授权问题）。

## 六、验收标准

1. `./gradlew assembleDebug` 成功产出 APK；
2. `./gradlew test` 音分换算、YIN 检测（合成正弦/钢琴波形）单测通过；
3. 三模式界面完整：钢琴可弹出声、听音选择可判分、模唱可出识别结果；
4. 麦克风权限流程完整（申请/拒绝/降级）。
